# Nombre de tu skill

Objetivo en una frase: qué queda hecho cuando esta skill termina bien.

## Pasos

1. Primer paso concreto (comando exacto, archivo exacto).
2. Segundo paso, con el criterio de verificación: cómo sabés que funcionó.
3. Último paso: qué se registra/commitea/avisa al terminar.

## Verificación

- Comando o chequeo que prueba que el resultado es correcto.
- Qué hacer si falla (el camino de vuelta también es parte del procedimiento).

## Límites

- Qué NO hace esta skill (p. ej.: "no toca `main`", "no borra datos").
- Cuándo parar y preguntar en vez de seguir.
