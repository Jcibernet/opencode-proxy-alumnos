# Caso 7 — PySpark en modo local

El mismo pipeline de ventas del caso 3, versión Spark. Corre en tu máquina
(modo local) — la API es idéntica a la del cluster de Databricks/Glue/Dataproc.

Requiere Java 17+ (`sudo apt install openjdk-17-jre-headless`).

```bash
uv run --with pyspark caso.py
```
